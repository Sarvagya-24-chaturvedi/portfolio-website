# 🌐 Personal Portfolio Website

A modern and responsive personal portfolio website designed to showcase my **projects, technical skills, experience, achievements, and contact information** in a clean and professional interface.

## 🚀 Live Demo

**Portfolio:** https://portfolio-website-brown-nine-62.vercel.app/

## 📌 About

This portfolio website serves as a central place to present my work as a **Computer Science Engineering student** interested in software development, DevOps, cybersecurity, blockchain, IoT, and emerging technologies.

The website is designed to provide recruiters, collaborators, and developers with a quick overview of my technical background and projects.

## ✨ Features

* 🎨 Clean and modern UI
* 📱 Responsive design for different screen sizes
* 💻 Project showcase
* 🛠️ Technical skills section
* 👨‍💻 Personal introduction
* 🔗 Social and professional links
* 📩 Contact information
* ⚡ Lightweight frontend with fast loading
* 🌐 Deployed using Vercel

## 🛠️ Tech Stack

* **HTML5** — Website structure
* **CSS3** — Styling, layout, and responsiveness
* **JavaScript** — Interactivity and dynamic behavior
* **Vercel** — Deployment and hosting
* **Git & GitHub** — Version control

## ⚙️ Run Locally

Clone the repository:

```bash
git clone https://github.com/Sarvagya-24-chaturvedi/portfolio-website.git
```

Navigate to the project directory:

```bash
cd portfolio-website
```

Open `index.html` in your browser, or use VS Code Live Server for local development.

## 🌍 Deployment

The website is deployed on **Vercel**, allowing the portfolio to be accessed online without requiring a local development environment.
